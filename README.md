# OSIRIS.EXE — Archive

A collection of self-contained interactive HTML pages. Open `index.html` (the archive hub) in any browser — no build step, no server, no dependencies.

## Contents

| Page | Description |
|---|---|
| `index.html` | Archive hub — landing page linking all transmissions |
| `osiris-exe-archive.html` | Full-screen recovered archive with embedded sentinel artwork, telemetry, CRT treatment, parallax, and manual signal pulse |
| `osiris-exe-signal-space.html` | Interactive 3D carrier-space visualization with 180 orbiting archive fragments (drag / wheel / double-click) |
| `osiris-motion-comic.html` | Four-scene motion comic: The Grid → The Disruptor → Pale Horse Protocol → OSIRIS Awake |
| `yotta.html` | "Yotta" WebGL fractal shader with live GLSL editor, by [Matthias Hurrle (@atzedent)](https://twitter.com/atzedent) — included as-is with original attribution |
